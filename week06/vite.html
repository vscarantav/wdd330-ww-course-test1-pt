S06 – Projeto: Final S06: Início – Ferramenta de Compilação Vite

Visão Geral

O Vite é uma ferramenta de compilação para auxiliar no desenvolvimento de aplicações web. O Vite foi a ferramenta usada no projeto de aprendizagem em equipe SleepOutside. Este guia ajudará você a começar a construir sua aplicação web final e individual usando o Vite.

Guia Passo a Passo para Começar

Node.js

Node.js é necessário para usar a ferramenta de compilação Vite.

  • Verifique sua versão do Node.js executando o seguinte comando no seu terminal: 
    node -v
    O número da versão deve ser 18+.
    Se necessário, você pode atualizar o Node.js executando o seguinte comando no seu terminal: 
    npm install -g node@latest

Se você não tiver o Node.js instalado corretamente, poderá baixá-lo no site oficial: Downloads do Node.js

Inicializar o Projeto

  1. Inicialize o projeto usando o vite digitando o seguinte comando no seu terminal: 
    npm create vite@latest
    Isso criará um novo projeto Vite no diretório atual.
  2. Serão solicitadas as seguintes informações:
    • Confirmação para instalar o pacote Vite. Você verá uma mensagem semelhante à seguinte: 
      Need to install the following packages:
  create-vite@x.x.x
  Ok to proceed? (y)
      Pressione a sua Enter tecla ou digite y e pressione Enter.
      O valor entre parênteses (y) é a entrada padrão.
    • Será solicitado o Nome do Projeto:. Digite um nome que seja semântico e conciso. Este será o nome da pasta que será criada para o seu projeto.
    • Em seguida, Selecione um framework: que deseja usar. Para este projeto, selecione Vanilla.
    • Em seguida, Selecione uma variante: que deseja usar. Para este projeto, selecione JavaScript.
    • Uma mensagem aparecerá dizendo algo como 
      Scaffolding project in
      seguido pela localização (pasta raiz e pasta do nome do projeto) que você selecionou. 
      Done. Now run:

Instalar Dependências e Iniciar o Servidor de Desenvolvimento

  1. Mude de diretório para a pasta do projeto que você acabou de criar digitando o seguinte comando no seu terminal: 
    cd <project-name>
    onde <project-name> é o nome da pasta que você criou na etapa anterior.
    Não inclua a sintaxe < e > no nome do seu projeto.
  2. Instale as dependências digitando o seguinte comando no seu terminal: 
    npm install
  3. Inicie o servidor de desenvolvimento digitando o seguinte comando no seu terminal: 
    npm run dev
  4. Sua aplicação Vite será iniciada e um servidor de desenvolvimento local (localhost) será aberto no seu navegador padrão. Navegue até a URL do localhost fornecida.
  5. No seu terminal, feche o servidor de desenvolvimento pressionando Ctrl + c (PC) ou Command + c (Mac) no seu teclado. Será solicitado que você confirme se deseja encerrar a tarefa em lote. Digite y e pressione Enter.

    Isso interromperá o servidor de desenvolvimento e o diretório atual do projeto será exibido no prompt.

Abrir o Projeto no VS Code

  1. Abra o projeto no Visual Studio Code (VS Code) digitando o seguinte comando no seu terminal: 
    code .

    O ponto (.) no final do comando é importante. Ele diz ao VS Code para abrir o diretório atual.

    Você também pode apenas iniciar o VS Code e abrir a pasta do projeto diretamente.

Gere a compilação da aplicação para produção

  1. No terminal do VS Code ou no terminal de sua escolha, execute o comando de compilação para abrir o index.html arquivo na src pasta. Você verá uma página HTML simples com o logotipo do Vite e um link para a documentação do Vite.
  2. Uma nova pasta chamada dist é adicionada à pasta do seu projeto.

É isso! Agora você está pronto para começar a construir sua aplicação web.
