S07 – Projeto: Final: Requisitos

Descrição

Seu projeto de aplicação web oferece a oportunidade de demonstrar sua compreensão dos conceitos e habilidades que você desenvolveu no curso. Esta página descreve os requisitos para o seu projeto final de aplicação web. Você estará criando e implantando uma aplicação web totalmente funcional usando HTML, CSS e JavaScript puro (sem frameworks ou bibliotecas permitidos).

Requisitos

A seguir está uma lista de requisitos para o projeto:

  • A pilha de tecnologia é HTML, CSS e JavaScript puro.

    É permitido usar um framework responsivo CSS e bibliotecas CSS para o seu projeto de aplicação web.

    Você NÃO pode usar nenhum framework ou biblioteca JS.

  • Usar pelo menos duas (2) APIs externas de terceiros.

    Uma dessas APIs de terceiros não pode ser o OpenWeatherMap.

  • Todas as funcionalidades expostas estão operacionais.
  • Ser uma combinação de marcação estática e gerada dinamicamente.
  • Incorporar animação CSS.
  • O código deve ser limpo, bem comentado e organizado. Mostre uma boa organização (Módulos ES, classes, etc).
  • O código está livre de erros (de acordo com as regras do ESLint).
  • A aplicação atende aos padrões de desenvolvimento web front-end usando HTML e CSS válidos e contemporâneos. Não há erros de acessibilidade e as páginas seguem as melhores práticas e recomendações básicas de SEO.
