S01 – Atividade de Aprendizagem: Revisão de Módulos JavaScript

Visão Geral

O conceito básico de um módulo é dividir um programa em partes mais fundamentais para portabilidade e manutenibilidade.

Preparação

Um módulo é um arquivo JavaScript. A funcionalidade de módulo foi desenvolvida na programação JavaScript para apoiar a ideia do princípio de responsabilidade única. Claro que um módulo pode conter muitas coisas, mas o conceito é dividir um programa em partes mais fundamentais para portabilidade e manutenibilidade.
