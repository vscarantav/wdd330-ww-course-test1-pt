S01 – Atividade de Aprendizagem: Git e o Fluxo de Trabalho do GitHub

Visão Geral

Ao longo do curso, você trabalhará com sua equipe no mesmo projeto de aprendizagem. Você não apenas precisará gerenciar tarefas, mas também o código compartilhado e suas contribuições individuais para a equipe. A tecnologia Git fornecerá a capacidade de colaborar de forma eficaz, rastrear alterações e publicar em um local de projeto comum.

Preparação

O Git é um sistema de controle de versão que permite rastrear alterações em seu código e colaborar com outras pessoas. O GitHub é uma plataforma baseada na web que usa o Git para controle de versão e oferece funcionalidades adicionais para colaboração, como pull requests e rastreamento de problemas.

A atividade apresentará a você algumas habilidades básicas no GitHub, incluindo:

  • Compreender repositórios, branches, commits e pull requests.
  • Criar uma branch, um commit e um pull request.
  • Mesclar um pull request.

Instruções da Atividade
