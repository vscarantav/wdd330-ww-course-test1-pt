Visão Geral

Nesta atividade, você aprenderá sobre a this palavra-chave em JavaScript e como ela é usada para acessar propriedades e métodos de um objeto.

O this método é uma palavra-chave especial em JavaScript que se refere à instância atual do objeto. Ele é usado para acessar propriedades e métodos do objeto em seu próprio contexto.

Nesta atividade, você aprenderá sobre a this palavra-chave em JavaScript e como ela é usada para acessar propriedades e métodos de um objeto.

Preparação

Em JavaScript, a this palavra-chave é útil ao trabalhar com objetos e elementos do DOM porque fornece uma referência dinâmica ao contexto atual — ou seja, o objeto ou elemento que está executando o código no momento. Ela tem significados diferentes dependendo de como é usada.

Isso permite a reutilização de código em métodos e manipuladores de eventos, suportando assim um código limpo e modular que é mais fácil de manter.

Quando você perde o contexto de this, ela não se refere mais ao objeto ou elemento que você espera, retornando assim undefined ou o objeto global como o window nos navegadores.

Por exemplo, se você usar uma função arrow em um escutador de eventos do DOM, this não apontará para o elemento.

document.querySelector("button").addEventListener("click", () => {
  console.log(this); // ❌ this is not referencing the button element as maybe expected.
  // Arrow functions do not have their own this.
});

Para preservar o controle de this, existem várias técnicas que são úteis, especialmente ao lidar com callbacks ou manipuladores de eventos.

  • O bind() método para definir explicitamente o valor de this em uma função. 
    const show = obj.showMessage.bind(obj); // Binds 'this' to obj
  • Como as funções arrow não têm seu próprio this, elas podem ser usadas para preservar o contexto de this em um escopo léxico envolvente, como em classes ou temporizadores.

Instruções da Atividade

Conclua as seguintes etapas para entender como e por que a this palavra-chave se comporta em diferentes contextos, como método de objeto, escopo global, manipulador de eventos. O objetivo é entender por que this é importante para acessar a instância atual do objeto.

Para avaliar seu conhecimento das perguntas da atividade, cole os trechos de código em um console do navegador para executá-los. Exemplos desta atividade também são fornecidos ao final da atividade para revisão.

  1. Dado o seguinte trecho de código, a que this.name se referirá?
    const person = {
  name: "Maria",
  greet: function () {
    console.log(`Hello, my name is ${this.name}`);
  }
};
   
person.greet();

    Qual você espera que seja a saída?

  2. O que acontece quando o método de personé extraído? 
    const greetFunction = person.greet; // Extracting the method
greetFunction(); // Calling the method

    A que this está vinculado agora?

  3. O exemplo anterior pode ser corrigido usando o bind() método para definir o valor de this explicitamente. 
    const greetFunction = person.greet.bind(person); // Binding 'this' to person:
greetFunction();

    Qual é a saída agora?

  4. O que acontece quando você usa uma função arrow no greet método? 
    const person = {
  name: "Maria",
  greet: () => {
    console.log(`Hello, my name is ${this.name}`); // Arrow function does not bind 'this' to the object
  }
};

person.greet();

    Qual é a saída agora?

  5. No trecho de código a seguir, a que this se refere no manipulador de eventos? 
    const button = document.querySelector("button");
button.addEventListener("click", function () {
  console.log(this); // 'this' refers to the button element
});
