S03 – Projeto: Individual Final – Brainstorm

Visão Geral

Esta tarefa é o primeiro passo no planejamento do seu projeto final: uma aplicação web que você projeta e constrói por conta própria, sobre um tópico de sua escolha. É separado da aplicação SleepOutside que você está construindo com sua equipe.

Dois projetos, rodando lado a lado

  • SleepOutside (equipe): o projeto de aprendizado que você continua a construir com sua equipe a cada semana. É onde vocês praticam juntos os conceitos do curso.
  • Projeto Final (individual): sua própria aplicação, construída apenas por você. É onde você mostra que pode aplicar esses mesmos conceitos de forma independente.

O propósito do brainstorm desta semana é gerar várias ideias possíveis para que, na próxima semana, você possa escolher uma e escrever uma proposta detalhada. O projeto final é concluído durante as semanas 5 a 7, então procure ideias que sejam úteis, envolventes e que tenham um escopo razoável para essa quantidade de tempo.

Instruções

  1. Faça um brainstorm de uma lista de pelo menos quatro (4) ideias de aplicações que pareçam interessantes para você.
  2. Para cada ideia, identifique pelo menos duas (2) APIs de terceiros que possam fornecer seus dados. Uma ideia só é viável se usar pelo menos duas fontes de API de terceiros.

    A página de Recursos de Front-end Web tem uma lista de possíveis APIs de terceiros que você pode usar para o seu projeto.

    ⚠️ Observe que você não tem permissão para usar a API OpenWeatherMap como uma das suas duas fontes para o seu projeto de aplicação web. Este serviço de API de clima foi atribuído e usado no WDD 231.

  3. Compartilhe suas ideias com sua equipe e outras pessoas para obter feedback. Seus colegas de equipe podem ajudá-lo a refinar suas ideias, mas cada aluno constrói seu próprio projeto final; não é um projeto de equipe.
  4. Você não precisa escolher uma ideia até a proposta da próxima semana. No entanto, se uma se destacar claramente, comece a planejar com base nela.

Ao fazer o brainstorm, comece com seus próprios interesses ou aplicações que preencham uma necessidade que você já vivenciou. Construir uma aplicação sobre algo que você conhece e gosta é mais fácil e envolvente do que construir uma sobre algo que você não conhece.

Envio

Envie sua lista de pelo menos quatro ideias para o projeto final. Para cada ideia, inclua uma descrição de uma ou duas frases e as APIs de terceiros que poderiam dar suporte a ela.
