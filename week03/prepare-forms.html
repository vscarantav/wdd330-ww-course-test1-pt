S03 – Atividade de Aprendizagem: S03: Formulários HTML e Validação de Entrada do Usuário

Visão Geral

Os formulários fornecem uma interface para entrada e interação do usuário. Eles são essenciais para coletar dados dos usuários, como em formulários de contato, pesquisas e checkouts de e-commerce. O HTML fornece um conjunto de elementos para criar formulários, permitindo que os desenvolvedores definam campos de entrada, botões e outros controles. Esta atividade se concentra em validar a entrada do usuário e aprimorar a experiência do usuário, garantindo que os dados inseridos estejam corretos e completos antes do envio.

Preparação

Validação de Formulário

A validação de formulário é o processo de verificar a entrada do usuário em um formulário antes de ele ser enviado para garantir que os dados atendam a critérios específicos. Isso pode incluir verificar campos obrigatórios, validar endereços de e-mail, garantir que os números estejam dentro de uma determinada faixa e muito mais.

HTML5 introduziu atributos nativos de validação de formulário que permitem aos desenvolvedores especificar regras de validação diretamente na marcação HTML. Esses atributos incluem required, pattern, min, max, e mais. Quando um formulário é enviado, o navegador verifica automaticamente esses atributos e fornece feedback ao usuário se a entrada não atender aos critérios especificados.

Aqui está um exemplo de um formulário HTML básico com validação:

<form id="myForm">
  <label for="email">Email:</label>
  <input type="email" id="email" name="email" required>
  <label for="age">Age:</label>
  <input type="number" id="age" name="age" min="18" max="100" required>
  <button type="submit">Enter Contest</button>
</form>

Neste exemplo, o formulário inclui um campo de entrada de e-mail que é obrigatório e um campo de entrada numérico para a idade que deve estar entre 18 e 100. O required atributo garante que o usuário não possa enviar o formulário sem preencher esses campos. Os min e max atributos na entrada de idade garantem que o usuário insira uma idade válida dentro do intervalo especificado.

CSS pode aprimorar a experiência do usuário fornecendo feedback visual para entradas de formulário válidas e inválidas. As :valid e :invalid pseudoclasses podem ser usadas para estilizar elementos de formulário com base em seu estado de validação. Por exemplo, você pode alterar a cor da borda de um campo de entrada para verde quando for válido e para vermelho quando for inválido. Esse feedback visual ajuda os usuários a identificar rapidamente quais campos precisam de atenção.

Aqui está um exemplo básico de como usar pseudoclasses CSS para validação de formulário:

input:valid { 
  border-color: green;
}

input:invalid {
  border-color: red;
}

JavaScript pode ser usado para aprimorar a experiência de validação de formulário fornecendo lógica de validação personalizada, manipulando cenários complexos de validação e fornecendo feedback em tempo real aos usuários. Isso pode incluir verificar se dois campos coincidem (por exemplo, confirmação de senha), validar formatos de entrada e impedir o envio do formulário se os dados forem inválidos.

Aqui está um exemplo do uso do JavaScript para validar um formulário:

const form = document.getElementById('myForm');
form.addEventListener('submit', function(event) {
  const email = document.getElementById('email').value;
  const age = document.getElementById('age').value;
  if (!email || !age) {
    event.preventDefault(); // Prevent form submission
    alert('Please fill out all required fields.');
  } else if (age < 18 || age > 100) {
    event.preventDefault(); // Prevent form submission
    alert('Age must be between 18 and 100.');
  }
});

Os métodos nativos do JavaScript são frequentemente usados e são blocos de construção essenciais para a validação de entrada do usuário. A validação de formulário moderna baseia-se neles ao enfatizar uma abordagem de defesa em profundidade (cliente E servidor), priorizando uma excelente experiência do usuário e, muitas vezes, aproveitando o poder de bibliotecas especializadas ou funcionalidades de framework para cenários mais complexos, tudo isso mantendo a acessibilidade em mente.

URLSearchParams

URLSearchParams é um objeto JavaScript nativo que fornece métodos para trabalhar com a string de consulta de uma URL. Ele permite acessar e manipular facilmente os parâmetros na string de consulta, tornando-o útil para tarefas como recuperar valores de envios de formulários ou construir URLs com parâmetros específicos.

pseudoclasses :valid e :invalid

As :valid e :invalid pseudoclasses no CSS são usadas para estilizar elementos de formulário com base em seu estado de validação. Elas fornecem feedback visual aos usuários sobre se a entrada fornecida atende aos critérios de validação especificados. Por padrão, os elementos de formulário são considerados válidos, a menos que tenham restrições de validação que não sejam atendidas.

A :valid A pseudoclasse aplica estilos a elementos de formulário que possuem uma entrada válida de acordo com as regras de validação definidas. Por exemplo, se um campo de entrada for required e o usuário tiver inserido um valor, o campo será considerado válido, e quaisquer estilos CSS definidos para :valid serão aplicados.

A :invalid pseudoclasse aplica estilos a elementos de formulário que possuem entrada inválida de acordo com as regras de validação definidas. Por exemplo, se um campo de entrada for required e estiver vazio, o campo será considerado inválido, e quaisquer estilos CSS definidos para :invalid serão aplicados.

Os seguintes atributos estão disponíveis para validação de formulário no HTML5:

  • required: Especifica que um campo de entrada deve ser preenchido antes de enviar o formulário.
  • pattern: Define uma expressão regular com a qual o valor de entrada deve corresponder.
  • min e max: Definem os valores mínimo e máximo para campos de entrada numéricos.
  • type: Especifica o tipo de entrada (por exemplo, email, number, url) que possui regras de validação integradas.
  • minlength e maxlength: Definem o número mínimo e máximo de caracteres permitidos em um campo de entrada de texto.
  • step: Especifica os intervalos numéricos válidos para campos de entrada numéricos.

Aqui estão exemplos de como usar as pseudoclasses :valid e :invalid no CSS:

input:valid {
  border-color: green;
}
input:invalid {
  border-color: red;
}

Neste exemplo, quando um campo de entrada for válido, a cor da sua borda mudará para verde, e quando for inválido, a cor da borda mudará para vermelho. Esse feedback visual ajuda os usuários a identificar rapidamente quais campos precisam de atenção e os incentiva a corrigir sua entrada.

Ao projetar formulários e validação, é importante lembrar que os usuários podem cometer erros ou ter diferentes níveis de proficiência técnica. Portanto, é essencial fornecer mensagens de erro claras e úteis quando a validação falhar. Evite culpar o usuário pelos erros; em vez disso, oriente-o sobre como corrigir sua entrada. Use uma linguagem amigável e forneça instruções específicas sobre o que precisa ser corrigido.

Para ajudar a melhorar a experiência do usuário, você pode restringir os estados válido/inválido usando as pseudoclasses :valid e :invalid no CSS para fornecer feedback visual aos usuários. Uma maneira de fazer isso é com a pseudoclasse :focus: Por exemplo, apenas dispare as pseudoclasses :valid/:invalid quando o campo de entrada estiver em foco. 

input:focus:invalid {
  border-color: red;
}

Instruções da Atividade

  1. Navegue até este 📑 Formulário de exemplo.
  2. Faça um fork do CodePen na sua própria conta do CodePen.
  3. Modifique o exemplo:
    1. Adicionando atributos de validação de formulário HTML aos elementos do formulário conforme achar adequado, por exemplo, required.
    2. Adicionando um campo que exija que o usuário insira o valor principal novamente para verificação.
    3. Use a validação em JavaScript para verificar imediatamente se os valores principais coincidem e notificar o usuário e exigir que os valores principais sejam inseridos novamente.
    4. Adicione ou modifique o código adicional para garantir que a saída NaN (Not a Number) não NÃO ocorra.
  4. Adicione as pseudoclasses valid e invalid de elementos de formulário em CSS para indicar visualmente que os campos individuais passaram na validação.
