Atividade em Equipe S03: Cabeçalho e Rodapé Dinâmicos

Visão Geral

Esta atividade finalizará o processo de conversão do site SleepOutside em um site dinâmico.

Instruções da Atividade

Conclua a seguinte Tarefa em equipe. Designe um membro da equipe como o "piloto principal" e colaborem em sua cópia do código. Todos na equipe devem estar ativamente engajados na escrita do código e contribuindo para a solução. Assim que a solução estiver funcionando, garanta que todos na equipe obtenham uma cópia do código. A cada semana, permita que outra pessoa seja o "piloto principal" da programação.

Existem muitos pontos onde exemplos de código foram fornecidos. Para aproveitar ao máximo esta atividade, não olhe para os exemplos até que sua equipe tenha tentado resolver essa seção. Então, depois de olhar o exemplo, resista à tentação de copiar/colar. Use os exemplos para obter correções ou ajudar a destravar.

O Cabeçalho e o Rodapé

O código para o cabeçalho e o rodapé do site deve ser igual ou quase igual em todas as páginas de um site. Você atualmente tem quatro cópias, uma em cada arquivo .html no site. Se precisar fazer uma alteração no cabeçalho, você terá que visitar cada página para mantê-las iguais. Isso é um incômodo com quatro páginas e se torna inadministrável em sites maiores.

Assim como foi para a lista de produtos, o uso de modelos pode ser uma solução para este problema também.

Há uma diferença desta vez, pois há apenas uma cópia do modelo, e há pouca informação que precisa ser atualizada. O cabeçalho e o rodapé são em grande parte estáticos. Em vez de incorporar o modelo no JavaScript como você fez com a listagem de produtos, desta vez você puxará o modelo HTML para um arquivo separado que poderá carregar com AJAX.

  1. Crie outro diretório chamado partials (certifique-se de colocar este novo diretório em src/public).
  2. Adicione dois novos arquivos ao diretório partials: header.html e footer.html.
  3. Copie o HTML de src/index.html página usando o interior dos elementos header e footer elementos e coloque esse HTML em seu respectivo arquivo.
  4. Adicione um id atributo aos elementos header e footer no arquivo index.html.

  5. Para carregar os modelos, você pode começar com a renderListWithTemplate função que você escreveu na semana passada, mas precisará fazer algumas alterações. Você está renderizando apenas um modelo em vez de uma lista. Você também precisa escrever uma função para requisitar o arquivo HTML com o cabeçalho e o rodapé.

    ✔ Copie a renderListWithTemplate função em utils.mjs e cole-a de volta em utils.mjs.
    ✔ Renomeie para renderWithTemplate.
  6. Modifique a nova função removendo o laço e passando quatro parâmetros:
    ✔ template
    ✔ parentElement
    ✔ data
    ✔ callback
  7. O cabeçalho deve ser em sua maioria HTML estático. No entanto, se a sua equipe tiver concluído os cartões de ícone do carrinho (animação ou número de itens), você pode precisar adicionar essa funcionalidade de volta. Este é um ótimo caso de uso para uma função de callback, mas o callback nem sempre será necessário.
    No renderWithTemplate função
    ✔ Insira o template no parentElement
    ✔ Adicione uma instrução if que verifique a existência do parâmetro callback; se ele existir, chame-o.
    Exemplo: utils.mjs renderWithTemplate 
    export function renderWithTemplate(template, parentElement, data, callback) {
  parentElement.innerHTML = template;
  if(callback) {
    callback(data);
  }
}

    Este exemplo usa innerHTML para inserir o modelo no parentElement. Outras opções possíveis incluem:

    parentElement.insertAdjacentHTML("afterbegin", template);
    const fragment = document.createRange().createContextualFragment(template);
                parentElement.replaceChildren(fragment);

    Quais são as vantagens e desvantagens de cada abordagem?

  8. Adicione uma função ao utils.mjs chamada loadTemplate. Esta função assíncrona busca o conteúdo do arquivo HTML fornecido um path. A resposta para o fetch é convertida em texto e retorna o conteúdo HTML como uma string.
    Exemplo: utils.mjs loadTemplate 
    export async function loadTemplate(path) {
  const res = await fetch(path);
  const template = await res.text();
  return template;
}
  9. Adicione uma função ao utils.mjs chamada loadHeaderFooter que possa ser exportada. Ela precisa ser capaz de fazer o seguinte:
    1. Carregar os modelos de cabeçalho e rodapé dos partials usando o loadTemplate.
    2. Obter os elementos reservadores de espaço (placeholders) de cabeçalho e rodapé do DOM.
    3. Renderizar o cabeçalho e o rodapé usando renderWithTemplate.
    Exemplo: utils.mjs loadHeaderFooter (apenas exemplo de cabeçalho) 
    const headerTemplate = await loadTemplate("../partials/header.html");

const headerElement = document.querySelector("#main-header");

renderWithTemplate(headerTemplate, headerElement);
  10. Atualize main.js para importar loadHeaderFooter e depois chamar essa função importada para carregar o cabeçalho e o rodapé no src/index.html.
  11. Faça a mesma coisa para
    • product_pages/index.html,
    • cart/index.html, e
    • cart/checkout.html (provavelmente você precisará criar um arquivo checkout.js para isso).
