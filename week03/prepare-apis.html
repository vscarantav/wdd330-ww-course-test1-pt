S03 – Atividade de Aprendizagem: APIs de Terceiros

Visão Geral

Neste ponto do seu próprio desenvolvimento, esperamos que você tenha percebido que os desenvolvedores não precisam escrever tudo sozinhos. Você viu que as ferramentas do navegador continuam a evoluir e a fornecer acesso a ferramentas integradas que possibilitam soluções de aplicação úteis por meio da abstração. APIs de Terceiros são outra maneira de aproveitar o trabalho de terceiros para construir suas próprias aplicações. APIs de Terceiros são interfaces fornecidas por serviços externos que permitem aos desenvolvedores acessar suas funcionalidades e dados. Essas APIs podem ser usadas para integrar funcionalidades como processamento de pagamentos, compartilhamento em redes sociais e recuperação de dados em suas próprias aplicações.

A abstração é o processo de remover ou suprimir detalhes para focar na ideia principal. Na programação, a abstração é uma maneira de reduzir a complexidade e aumentar a eficiência, ocultando detalhes desnecessários e mostrando apenas as funcionalidades essenciais de um objeto ou sistema, como trabalhar por meio de uma interface, uma Interface de Programação de Aplicações ou API.

Preparação

Para se preparar para consumir APIs de terceiros, você deve entender os seguintes conceitos:

  • Endpoints de API: As URLs específicas onde a API pode ser acessada.
  • Métodos HTTP: Os métodos usados para interagir com a API, como GET, POST, PUT e DELETE.
  • Autenticação: O processo de verificação da identidade do usuário ou aplicação que faz a requisição.
  • Formatos de Resposta: O formato no qual a API retorna dados, como JSON ou XML.
  • Tratamento de Erros: Como tratar erros que podem ocorrer ao fazer requisições para a API.

Aqui está um exemplo de API que suporta esses conceitos:

https://jsonplaceholder.typicode.com/posts

Este serviço gratuito de API simulada simula uma API do mundo real e é comumente usado para fins de testes e prototipagem. Os recursos disponíveis no jsonplaceholder incluem posts (100 registros), comentários (500), álbuns (100), fotos (5000), tarefas (200) e usuários (10). Cada recurso possui seu próprio conjunto de endpoints e suporta os mesmos métodos HTTP. Esses recursos possuem relacionamentos, por exemplo, álbuns possuem fotos e posts possuem comentários. Por exemplo, o /posts endpoint permite livremente criar, ler, atualizar e excluir posts.

Esta API usa os seguintes métodos HTTP:

  • GET: Recupera uma lista de posts ou um post específico.
    Exemplo de endpoint: GET /posts recupera todos os posts, enquanto GET /posts/{id} recupera um post específico por ID.
  • POST: Cria um novo post.
    Exemplo: POST /posts cria um novo post com os dados fornecidos no corpo da requisição.
  • PUT: Atualiza um post existente.
    Exemplo: PUT /posts/{id} atualiza um post existente por ID com os dados fornecidos no corpo da requisição.
  • DELETE: Exclui um post.
    Exemplo: DELETE /posts/{id} exclui um post específico por ID.

Aqui está um exemplo usando o método GET padrão

const todo = document.getElementById('todo-output');

async function getTodo() {
  try {
    const response = await fetch('https://jsonplaceholder.typicode.com/todos/77');
    if (!response.ok) {
      throw new Error(`HTTP error! Status: ${response.status}`);
    }
    const json = await response.json();
    todo.textContent =  json;
  } catch (error) {
    console.error('There was a problem fetching the data:', error);
  }
}

todo.textContent = 'Loading...';
getTodo();

Este código usa a Fetch API para fazer uma GET requisição ao /todos/77 endpoint da API JSONPlaceholder. Ele recupera um único item de tarefa com o ID 77 e exibe esse objeto conforme mostrado abaixo. Se houver um erro, ele registra a mensagem de erro no console.

dados do jsonplaceholder do exemplo

jsonplaceholder.typicode.com não requer autenticação por ser um serviço básico e gratuito para prototipagem. A maioria das APIs requer algum tipo de autenticação para garantir que apenas usuários autorizados possam acessar a API e seus recursos. A autenticação pode ser feita usando uma chave de API, OAuth ou outros métodos. O método de autenticação específico usado por uma API dependerá do provedor da API e do nível de segurança necessário para ela.

Para obter mais informações sobre esta API, você pode consultar a documentação do JSONPlaceholder.

Instruções da Atividade

Nesta atividade, use o serviço de API simulado jsonplaceholder.typicode.com para retornar todos os usuários e exibi-los na tela em uma lista não ordenada.

Use os seguintes requisitos para concluir a atividade:

  1. Use a async/await abordagem para fazer o Fetch da API e realizar uma requisição GET para o /users endpoint da API JSONPlaceholder.
  2. Recupere todos os registros de usuários a partir dos dados da resposta.
  3. Exiba os registros individuais de usuários como itens de lista li exibindo o 'name' e o 'email' de cada usuário.
  4. Trate quaisquer erros que possam ocorrer durante a requisição.
