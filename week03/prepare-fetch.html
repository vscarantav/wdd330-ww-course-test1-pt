S03 – Atividade de Aprendizagem: S03: Revisão: A Fetch API

Visão Geral

Uma chave no desenvolvimento web moderno é fazer requisições HTTP assíncronas para se comunicar com servidores sem forçar uma atualização completa da página. Esta atividade ajudará você a revisar como usar a Fetch API para fazer essas requisições.

Preparação

A fetch api é uma maneira moderna de fazer requisições HTTP. É uma Web API nativa (incorporada) suportada pela maioria dos navegadores modernos e é uma ótima maneira de começar a fazer requisições para APIs. A fetch API retorna uma promise que se resolve na resposta da requisição. Essa resposta pode então ser convertida para JSON ou texto, dependendo do tipo de dados que você espera receber de volta do servidor.

Se necessário, revise o seguinte recurso do WDD 231:

  • A Fetch API

Aqui está um exemplo simples de como usar a fetch API:

const url = 'https://pokeapi.co/api/v2/pokemon/1';
const options = {
  method: 'GET',
  headers: {
    'Content-Type': 'application/json',
    'Accept': 'application/json'
      
  }
};
fetch(url, options)
  .then(response => {
    if (!response.ok) {
      throw new Error('Network response was not ok');
    }
    return response.json();
  })
  .then(data => {
    console.log('first: ', data);
    console.log('second: ', data.name);
  })
  .catch(error => {
    console.error('There was a problem with the fetch operation:', error);
  });
