S04 – Atividade de Aprendizagem: Conceitos Avançados de Funções

Visão Geral

O motor do JavaScript oferece maneiras poderosas de resolver problemas usando funções para organizar o código e executar tarefas específicas. Você já sabe como definir e chamar funções, passar argumentos para elas e lidar com seus valores de retorno. Nesta atividade, você explorará como as funções do JavaScript são executadas, como elas interagem com a pilha de chamadas e como podem ser usadas como objetos de primeira classe.

Preparação

Esta atividade de aprendizagem se concentra em uma compreensão mais profunda das funções, incluindo o contexto de execução, a pilha de chamadas, callbacks e funções de ordem superior.

O que é um objeto de primeira classe?

No JavaScript, as funções são objetos de primeira classe. Isso significa que as funções podem ser tratadas como qualquer outro objeto no JavaScript. Elas podem ser atribuídas a variáveis, passadas como argumentos para outras funções, retornadas de funções e armazenadas em estruturas de dados como arrays e objetos. Isso permite um alto grau de flexibilidade e reutilização no seu código.

Como você sabe, as funções podem ser criadas usando declarações de função, expressões de função, e arrow functions. Cada um desses métodos tem sua própria sintaxe e casos de uso, mas todos criam funções de primeira classe que podem ser usadas da mesma forma.

Aqui está um exemplo simples que demonstra a passagem de uma função como argumento:

const fullNames = ["Aday Lovina", "Benstras Turing", "Grace Ojo"];
const lastNames = fullNames.map(function getLastName(name) {
  return name.split(" ").slice(-1)[0];
});
  • map() é uma função de ordem superior. Ela retorna um novo array.
  • getLastName() é a função passada como argumento para map
  • name é o parâmetro da função getLastName()
  • name.split(" ") divide a string em um array de palavras
  • slice(-1)[0] obtém o último elemento do array
  • return retorna o sobrenome
  • lastNames é o array de sobrenomes retornado pela map() função

Funções de Ordem Superior são funções que podem receber outras funções como argumentos ou retornar funções como seu resultado. Isso permite um código mais flexível e reutilizável, bem como a capacidade de criar funcionalidades mais complexas combinando funções simples. Elas são uma parte fundamental e principal da programação funcional e incluem funções que você já esteve usando, incluindo:

  • map() – cria um novo array com os resultados da chamada de uma função fornecida em cada elemento do array chamador.
  • filter() – cria um novo array com todos os elementos que passam no teste implementado pela função fornecida.
  • reduce() – executa uma função reducer (que você fornece) em cada elemento do array, resultando em um único valor de saída.
  • forEach() – executa uma função fornecida uma vez para cada elemento do array.

Contexto de Execução

O Contexto de Execução é o ambiente no qual uma função é executada. Ele inclui o escopo da função, o valor de 'this' e quaisquer variáveis que estejam definidas dentro da função. Entender o contexto de execução é crucial para compreender como as funções funcionam no JavaScript.

O exemplo a seguir demonstra como os contextos são criados e como as cadeias de escopo determinam qual variável pode ser acessada em diferentes níveis. Você deve executar este código no console para verificar o conceito.

const globalVariable = "I'm Global";

function outerFunction() {
  const outerVariable = "I'm Outer";  

  function innerFunction() {
    const innerVariable = "I'm Inner";
    console.log(globalVariable); // I'm Global
    console.log(outerVariable); // I'm Outer
    console.log(innerVariable); // I'm Inner
  }

  innerFunction();
  console.log(innerVariable); // ReferenceError: innerVariable is not defined
  console.log(this); // in this scope, refers to the global object (the window in browsers)
}
outerFunction();

Neste exemplo, a innerFunction() tem acesso às variáveis definidas em seu próprio escopo (innerVariable), bem como às variáveis definidas em seu escopo pai (outerVariable) e no escopo global (globalVariable). No entanto, a outerFunction() não tem acesso à innerVariable, porque ela está definida em um escopo diferente.

No exemplo, a this palavra-chave refere-se ao objeto global (o window nos navegadores) porque outerFunction() é chamada no contexto global. Se você chamasse innerFunction() diretamente, this se referiria à própria função.

Hoisting

Hoisting é um mecanismo do JavaScript no qual variáveis e declarações de função (mas não arrow functions) são movidas para o topo do seu escopo contido durante a fase de compilação ou de "Criação". Ele também configura a this associação. Hoisting é um mecanismo que afeta o que está disponível e quando, antes que qualquer código seja realmente executado.

Pilhas de Chamada

Pilhas de Chamada no JavaScript é uma estrutura de dados que acompanha as chamadas de função. Quando uma função é chamada, ela é adicionada à pilha e, quando retorna, é removida da pilha. Isso permite que o JavaScript acompanhe onde está no código e quais funções estão sendo executadas no momento.

Aqui está um exemplo que você pode executar no console: 

function firstFunction() {
  console.log("First Function");
  secondFunction();
  console.log("Back to First Function");
}

function secondFunction() {
  console.log("Second Function");
  thirdFunction();
  console.log("Back to Second Function");
}

function thirdFunction() {
  console.log("Third Function");
  // Uncomment the next line to see the stack overflow error (RangeError)
  // thirdFunction(); 
  console.log("Back to Third Function");
}

firstFunction();

Neste exemplo, quando firstFunction() é chamada, ela se adiciona à pilha de chamadas. Em seguida, ela chama secondFunction(), que se adiciona à pilha. Por fim, ela chama thirdFunction(), que se adiciona à pilha. Quando thirdFunction() retorna, ela é removida da pilha e o controle volta para secondFunction(), e depois de volta para firstFunction().
