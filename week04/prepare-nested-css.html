S04 – Atividade de Aprendizagem: CSS Aninhado

Visão Geral

O CSS aninhado moderno é uma forma de escrever CSS mais legível e de fácil manutenção, especialmente para grandes projetos. Ele permite aninhar regras CSS dentro de outras regras, o que pode ajudar a manter seus estilos organizados e potencialmente reduzir a quantidade de dados CSS que precisam ser baixados.

A estrutura de arquivos também é importante ao usar CSS aninhado. É comum ter um arquivo CSS principal que importa outros arquivos CSS, os quais podem ser organizados por componentes ou funcionalidades. Isso permite que você mantenha seus estilos modulares e mais fáceis de gerenciar.

Nesta atividade, você aprenderá a usar CSS aninhado.

Preparação

Aqui está um exemplo de CSS aninhado:

.container {
  display: flex;
  flex-direction: column;
  place-items: center;

  h1 {
    font-size: 2rem;
    color: #333;
  }

  p {
    font-size: 1rem;
    color: #666;
  }

  button {
    background-color: #007BFF;
    color: white;
    padding: 10px 20px;
    border: none;
    border-radius: 5px;
    cursor: pointer;

    &:hover {
      background-color: #0056b3;
    }

    &:focus {
      outline: none;
      box-shadow: 0 0 0 2px rgb(0 123 255 / 50%);
    }
  }
}

No exemplo acima, a .container classe contém regras aninhadas para h1, p, e button elementos. O botão também possui regras aninhadas para os :hover e :focus estados.

Instruções da Atividade

Converta este CSS tradicional em um formato CSS aninhado moderno.

footer {
  background-color: #333;
  color: white;
  padding: 20px;
  position: relative;
  bottom: 0;
  width: 100%;
  z-index: 1000;
}
 
footer a {
  color: white;
  text-decoration: none;
}

footer a:hover {
  text-decoration: underline;
  color: yellow;
} 
  
footer p {
  font-size: smaller;
}
Avalie Seu Conhecimento 
footer {
  background-color: #333;
  color: white;
  padding: 20px;
  position: relative;
  bottom: 0;
  width: 100%;
  z-index: 1000;

  & a {
    color: white;
    text-decoration: none;

    &:hover {
    text-decoration: underline;
    color: yellow;
    } 
  }

  & p { 
    font-size: smaller;
  }
}

Neste exemplo, seletores filhos como a {} ou p {} são tratados automaticamente como seletores aninhados em relação ao pai e, portanto, o & que os precede pode ser omitido.

As media queries podem ser aninhadas diretamente dentro de uma regra de estilo para aplicar estilos a esse seletor pai em condições específicas. Por exemplo, se você quisesse aplicar um estilo diferente ao rodapé quando a largura da tela for menor que 600px, você poderia fazer assim:

footer {
  background-color: #333;
  color: white;
  padding: 20px;
  position: relative;
  bottom: 0;
  width: 100%;
  z-index: 1000;
  @media (max-width: 600px) {
    background-color: #444;
    padding: 10px;
    font-size: smaller;
  }
  & a {
    color: white;
    text-decoration: none;
    &:hover {
      text-decoration: underline;
      color: yellow;
    }
  }
  & p {
    font-size: smaller;
  }
}
