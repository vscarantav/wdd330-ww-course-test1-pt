S04 – Atividade de Aprendizagem: Animações e Transições CSS

Visão Geral

Adicionar animações com CSS pode aprimorar a experiência do usuário, melhorando a estética e o branding, fornecendo feedback visual e tornando o site mais atraente por meio de transições e movimentos sutis. A chave é aplicá-las de uma forma útil que não distraia do propósito e da intenção do conteúdo.

Preparação

Animações CSS são aplicadas usando a @keyframes regra e a animation propriedade. A @keyframes regra define a animação, enquanto a animation propriedade a aplica a um elemento. A animação pode ser aplicada a qualquer elemento HTML, incluindo texto, imagens e outros elementos.

As animações CSS são melhores para animações mais complexas, baseadas em keyframes e/ou contínuas.

Este exemplo, Animação CSS, usa animation com @keyframes para ilustrar alguns resultados em um gráfico de barras verticais.

  • Revisão: Animações CSS – WDD 231

Transições CSS são uma maneira mais simples de animar elementos. Elas são frequentemente disparadas por uma mudança de estado, como mudanças de classe JS ou pseudo-classes integradas (:hover). Elas são definidas por um estado inicial e final e você precisa de interação do usuário ou script para disparar a mudança de estado.

As transições CSS são melhores para mudanças de estado pontuais. Elas são uma ótima maneira de adicionar interatividade sutil e normalmente ocorrem de forma suave ao longo do tempo

Estes exemplos, Transição CSS, ilustram alguns dos usos mais comuns com efeito hover em botões, menus sanfona e efeitos de aparecimento/desaparecimento gradual (fade in/out).

Instruções da Atividade

Comece a planejar como você usará animações e transições CSS em seu projeto individual de aplicação web.
