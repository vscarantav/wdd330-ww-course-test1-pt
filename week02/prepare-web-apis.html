S02 – Atividade de Aprendizagem: S02: APIs Web Nativas do Navegador

Visão Geral

A esta altura, no seu próprio desenvolvimento, você provavelmente já percebeu que os desenvolvedores não precisam escrever tudo sozinhos e que você já usou APIs Web que são nativas (incorporadas) do navegador em seu trabalho. Existem muitas APIs nativas e ainda mais interfaces (tipos de objeto) disponíveis para serem usadas no desenvolvimento web.

Você já usou as APIs DOM, Fetch e localStorage em sua jornada de desenvolvimento web.

Esta atividade de aprendizagem se concentra em algumas dessas APIs Web suportadas em navegadores modernos e no tempo de execução do Node.js.

Preparação

Storage API (sessão)

A sessionStorage API é ótima para dados temporários, como armazenar o progresso do formulário durante uma única sessão do usuário, acompanhar qual aba está ativa e manter sinalizadores apenas enquanto a aba estiver aberta. Ela não requer um banco de dados nem o uso de cookies.

Ela está disponível apenas durante uma sessão ativa e é limpa quando a aba é fechada, tornando-a um pouco mais segura do que localStorage dado que os dados do localStorage persistem mesmo após o navegador ser fechado.

Os dados em sessionStorage não são completamente seguros e não devem ser usados para armazenar informações sensíveis.

Para definir um item no armazenamento de sessão, use esta forma geral onde chave é o identificador e valor são os dados que você deseja armazenar:

sessionStorage.setItem('key', 'value');

Para recuperar um item do armazenamento de sessão, use esta forma geral:

sessionStorage.getItem('key');

Para remover um item do armazenamento de sessão, use:

sessionStorage.removeItem('key');

Para limpar todos os itens do armazenamento de sessão, use:

sessionStorage.clear();

Para verificar se um item do armazenamento de sessão existe, use esta forma geral:

if (sessionStorage.getItem('key') !== null) { 
  // item exists
}

API de Validação

A Validation API é uma API nativa do navegador que permite responder à validação da entrada do usuário em formulários HTML. Ela fornece uma maneira de verificar se os atributos definidos no HTML input foram atendidos. Coisas como ser required, ter um formato específico ou estar dentro de uma determinada faixa, por exemplo, usando min e max.

Para usar a Validation API, você pode usar o checkValidity() método em um elemento de entrada. Este método retorna um valor booleano indicando se a entrada é válida ou não. Se a entrada for inválida, você pode usar o setCustomValidity() método para definir uma mensagem de erro personalizada.

Para verificar se uma entrada é válida, use esta forma geral:

if (inputElement.checkValidity()) {
  // input is valid
} else {
  // input is invalid
  inputElement.setCustomValidity('Custom error message');
}

A variável, inputElement, refere-se ao elemento de entrada referenciado que você deseja validar.

Geolocation API

A Geolocation API é uma API nativa do navegador que permite acessar a localização geográfica do usuário. Ela fornece uma maneira de obter a posição atual do usuário em latitude e longitude, monitorar alterações de posição e tratar erros que possam ocorrer ao tentar acessar a localização.

Para usar a Geolocation API, você pode usar o navigator.geolocation objeto. Este objeto fornece métodos para obter a posição atual do usuário e monitorar alterações de posição.

Para obter a posição atual do usuário, use esta forma geral:

navigator.geolocation.getCurrentPosition(successCallback, errorCallback);

A variável, successCallback, é uma função que é chamada quando a posição é recuperada com sucesso. A variável, errorCallback, é uma função que é chamada quando ocorre um erro ao recuperar a posição.

Para monitorar alterações de posição, use esta forma geral:

navigator.geolocation.watchPosition(successCallback, errorCallback);

O exemplo a seguir usa o getCurrentPosition() método para obter sua posição em latitude e longitude e determinar uma região geográfica do mundo.

Ver Código de exemplo 
const button = document.querySelector("#location-button");
const location = document.querySelector(".location");
        
button.addEventListener("click", function () {
  if (navigator.geolocation) {
    navigator.geolocation.getCurrentPosition(
      function (position) {
        const latitude = position.coords.latitude;
        const longitude = position.coords.longitude;
        // output
        location.innerHTML = `Latitude: ${latitude} 🧭 Longitude: ${longitude}`;
        location.innerHTML += `
Region: ${getRegion(latitude, longitude)}`;
      },
      function (error) {
        location.textContent = `Error: ${error.message}`;
      }
    );  
    } else {
      location.textContent = "Geolocation is not supported by this browser.";
    }
});

function getRegion(lat, lon) {
  if (lon > 180) lon -= 360; //normalize to -180..180

  switch (true) {
    // North America (excl. Mexico/Central America)
    case lat >= 24 && lat <= 83 && lon >= -172 && lon <= -52:
      return "North America" ;
    // Mexico and Central America
    case lat >= 7 && lat < 24 && lon >= -118 && lon <= -77:
      return "Mexico and Central America";
    // South America
    case lat >= -56 && lat <= 13 && lon >= -82 && lon <= -34:
      return "South America";
    // Europe
    case lat>= 35 && lat <= 71 && lon >= -25 && lon <= 45:
      return "Europe";
    // Africa
    case lat >= -35 && lat <= 37 && lon >= -17 && lon <= 52:
      return "Africa";
    // Asia
    case lat >= 5 && lat <= 80 && lon >= 45 && lon <= 180:
      return "Asia";
    // Oceania
    case lat >= -50 && lat <= 0 && lon >= 110 && lon <= 180:
      return "Oceania";
    default:
      return "Not mapped";
  }
}

Seu navegador solicitará permissão para permitir que esta página descubra sua localização.
