S02 – Atividade de Aprendizagem: setTimeout / setInterval

Visão Geral

Às vezes, você vai querer executar uma função depois que um determinado período de tempo tiver passado e não imediatamente. Por exemplo, você pode querer adiar a execução de uma função até que o usuário termine de digitar em um campo de entrada. É aqui que os setTimeout() e setInterval() métodos são úteis.

Nesta atividade, você descobrirá como criar eventos temporizados em aplicações web.

Preparação

Os setTimeout() e setInterval() métodos fazem parte do Window objeto. Eles são usados para agendar a execução de código em um momento posterior. O método setTimeout() chama uma função ou avalia uma expressão após um número especificado de milissegundos.

Instruções da Atividade

Pratique o uso de setTimeout() e setInterval() para criar um temporizador de contagem regressiva em JavaScript.

HTML

  • Crie um arquivo HTML com uma <h1> tag para exibir a contagem regressiva (ex.: <h1 id="countdown"></h1>).
  • Adicione um botão para iniciar a contagem regressiva (ex.: <button id="startButton">Start</button>).

JavaScript

Escreva um código JavaScript para:

  • Obter referências para a <h1> e para o botão usando document.getElementById().
  • Criar uma variável para armazenar o tempo inicial (ex.: 10 segundos).
  • Adicionar um escutador de eventos ao botão que inicia a contagem regressiva quando clicado.
  • Dentro do escutador de eventos:
    • Usar setInterval() para decrementar a contagem regressiva a cada segundo.
    • Atualizar a <h1> tag com o tempo restante.
    • Usar setTimeout() para parar a contagem regressiva quando ela chegar a 0.
    • Exibir uma mensagem como "O tempo acabou!" quando a contagem regressiva terminar.

Desafios Bônus

  • Adicionar um botão "Pausar/Retomar" para controlar a contagem regressiva.
  • Permitir que o usuário forneça uma entrada de tempo inicial personalizado.
  • Estilizar o temporizador de contagem regressiva com CSS para torná-lo visualmente atraente.
Solução de Amostra Parcial 
const countdownDisplay = document.getElementById('countdown');
const startButton = document.getElementById('startButton');

let timeLeft = 10;

startButton.addEventListener('click', () => {
  setInterval(() => {
    if (timeLeft >= 0) {
      countdownDisplay.textContent = timeLeft;
      timeLeft--;
    } else {
      // Stop the countdown and display a message
    }
  }, 1000); 
});
