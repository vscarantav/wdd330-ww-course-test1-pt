S02 – Atividade de Aprendizagem: S02: A Interface Window

Visão Geral

Você já usou o window objeto muitas vezes ao trabalhar com JavaScript. Por exemplo, você manipulou o DOM e foi o objeto global window objeto que forneceu o acesso. Você também usou o window.localStorage para armazenar dados básicos no navegador.

Você pode ter notado que a window sintaxe é frequentemente omitida porque é o objeto global no ambiente do navegador e, portanto, não é necessária.

window.document.querySelector(".message")
// can be written as:
document.querySelector(".message")
// and
window.localStorage.setItem("key", "value")
// can be written as:
localStorage.setItem("key", "value")

Preparação

A interface Window define as propriedades e métodos disponíveis para o objeto global como o .location, .localStorage, e alert(). É o objeto de nível superior na hierarquia do JavaScript, o pai de todos os outros objetos no navegador.

Ela fornece acesso às funcionalidades do navegador, incluindo métodos para manipular a janela do navegador e acesso às propriedades da janela. Cada aba no navegador é representada por seu próprio window objeto. No entanto, algumas propriedades e métodos se aplicam à janela do navegador que o contém.

Por exemplo, as propriedades window.innerWidth e window.innerHeight retornam a largura e a altura da viewport da janela do navegador.

Insira estas duas linhas de código no painel do console do DevTools do seu navegador.

window.innerWidth
window.innerHeight
