S02 – Atividade de Aprendizagem: Elemento Modelo

Visão Geral

Às vezes você vai querer construir conteúdo, mas não renderizar esse conteúdo até mais tarde. Por exemplo, você pode querer construir uma lista de itens, mas não renderizá-los até que o usuário clique em um botão. O elemento <template> do HTML permite fazer exatamente isso.

Preparação

O HTML <template> elemento não é renderizado pelo navegador até ser evocado por script. O <template> elemento é útil para marcação HTML repetida contendo registros ou outros dados que são usados repetidamente.

Aqui está um exemplo de elemento modelo HTML:

<template id="product-card">
  <section class="card">
    <h2></h2>
    <p></p>
    <p></p>
    <img class="tn" src="" alt="" loading="lazy" width="100" height="200">
  </section>
</template>

No exemplo acima, o elemento modelo é usado para criar um cartão de produto. O template contém um section elemento com um class de "card" e inclui um elemento h2 para o nome do produto, dois p elementos para a descrição e preço do produto, etc., e um img elemento para a imagem do produto.

O template elemento não é renderizado até ser clonado e inserido no DOM.

Aqui está um exemplo de como clonar e inserir o modelo no DOM:

const template = document.getElementById("product-card");
const productList = document.getElementById("product-list");
    
products.forEach((product) => {
  const clone = template.content.cloneNode(true);
  const [title, desc, price, img] = clone.querySelectorAll("h2, p, p, img");
    
  title.textContent = product.name;
  desc.textContent = product.description;
  price.textContent = product.price;
  img.src = product.image;
  img.alt = product.name;
    
  productList.appendChild(clone);
});

No exemplo acima, o modelo é clonado e o conteúdo é preenchido com dados do products array. O modelo clonado é então adicionado ao final de um product-list elemento. Observe o uso do .cloneNode() método e a seleção dos elementos do modelo como const variáveis.
