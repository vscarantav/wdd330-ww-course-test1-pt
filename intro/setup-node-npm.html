e Instalação do Node e NPM

Visão Geral

O Node e o gerenciador de pacotes do Node (NPM) são usados para instalar e gerenciar as ferramentas e bibliotecas que serão usadas neste curso e são obrigatórios.

Node e NPM

O Node é um tempo de execução JavaScript que ganhou muita popularidade nos últimos anos. Existem muitas ferramentas e utilitários úteis que podem ser executados usando ele. O NPM é o Node Package Manager (Gerenciador de Pacotes do Node). Ele é instalado automaticamente com o Node e é usado para adicionar e remover utilitários.

Para instruções mais detalhadas, visite: http://blog.teamtreehouse.com/install-node-js-npm-windows

Verificar Instalação Anterior

Antes de instalar o Node.js, certifique-se de que você ainda não tem o Node.js instalado.

  1. Abra uma janela do terminal (Mac) ou do prompt do CMD/PowerShell (Windows).
  2. Digite node -v ou node --version.
  3. Se um número de versão for fornecido (ex.: v), você já tem o Node.

Instalação

Usuários do Windows
  1. Baixe a versão recomendada LTS do instalador do Windows no site do Node.js®.
  2. Execute o instalador (o arquivo .msi que você baixou na etapa anterior).
  3. Siga as instruções no instalador (Aceite o contrato de licença, clique no botão NEXT várias vezes e aceite as configurações de instalação padrão).
  4. Reinicie o seu computador. Você não poderá executar o Node.js® até reiniciar o seu computador.
  5. Para verificar se funcionou, digite o seguinte no prompt de comando: node -v. Se você receber de volta o número da versão, está tudo pronto.
Usuários do macOS

Para o Mac, instale a ferramenta Node Version Manager (nvm) primeiro e, em seguida, use-a para instalar o Node. Há algumas vantagens em fazer dessa forma... a maior delas é que torna muito fácil alternar entre versões do Node quando necessário (acontece mais do que você imagina como desenvolvedor) e as ferramentas de desenvolvedor da Apple são necessárias. Essas ferramentas podem ser obtidas de duas maneiras:

  1. Se você acha que algum dia vai querer compilar aplicativos nativos para MacOS ou iOS, baixe e instale o XCode. O software de desenvolvimento XCode da Apple é usado para compilar aplicativos para Mac e iOS, mas também inclui as ferramentas necessárias para compilar software para uso no seu Mac. O XCode é gratuito e você pode encontrá-lo no XCode no iTunes. Depois de instalá-lo, abra-o pelo menos uma vez para aceitar os Termos. A próxima etapa não funcionará a menos que você faça isso.
  2. *Recomendado para a maioria! Se você não quiser baixar e instalar o XCode completo (ele é bastante grande), poderá instalar apenas as ferramentas de desenvolvedor seguindo estas instruções.

Instalar o Node e o NPM com o nvm é bem simples.

  1. Para instalar o nvm, abra o aplicativo Terminal e digite: 
    curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.37.2/install.sh | bash
  2. Assim que a instalação do nvm for concluída, você poderá obter a cópia mais recente da versão de Suporte a Longo Prazo (LTS) digitando o seguinte: 
    nvm install --lts
  3. Para verificar se funcionou, digite o seguinte no terminal: node -v. Se você receber de volta o número da versão, está tudo pronto.

Desde o macOS 10.15, o shell padrão é o zsh e o nvm procurará o .zshrc para atualizar, sendo que nenhum está instalado por padrão. Se você receber um erro ao instalar acima, crie este arquivo digitando o seguinte em seu terminal: 

touch ~/.zshrc
