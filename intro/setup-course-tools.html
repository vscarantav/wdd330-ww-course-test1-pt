S01 – Configuração: S01: Ferramentas

Visão Geral

Esta atividade de configuração irá prepará-lo com as ferramentas de desenvolvimento e do curso necessárias para concluir as atividades e tarefas.

Instruções

Editor de Código

Um bom editor de código é essencial para o desenvolvimento de software. Este curso usa Visual Studio Code (VS Code).

  1. Verifique se você tem uma instância funcional do VS Code em execução e instale-a, se necessário, a partir de code.visualstudio.com.
  2. Se você já tem o VS Code instalado, verifique se há atualizações usando o menu Help ► Check for Updates...
  3. Personalizar o VS Code para automatizar seu ciclo de desenvolvimento e auxiliar nas rotinas de desenvolvimento.
Recursos Opcionais
  • Ajuda do VS Code
  • Documentação do VS Code

Node / Gerenciador de Pacotes do Node (NPM)

O Node.js é um ambiente de tempo de execução (do lado do servidor) JavaScript construído sobre o motor de JavaScript V8 do Chrome. O NPM é o gerenciador de pacotes node para o Node.js.

  1. Instale a versão LTS (Suporte a Longo Prazo) atual do node.
    Siga as instruções para o seu sistema operacional encontradas nesta página de configuração de software.
  2. Verifique se você tem o Node instalado abrindo um terminal (Mac) ou prompt do CMD/PowerShell (Windows) e digitando node -v e npm -v.
Recursos Opcionais
  • Como usar a linha de comando/prompt para o seu sistema operacional: MacOS | Windows

Git e GitHub

  1. Verifique se você tem o Git instalado abrindo um terminal (Mac) ou prompt do CMD/PowerShell (Windows) e digitando git --version. Se receber um erro, você precisa instalar o Git.
  2. Você precisará ter uma conta no GitHub.
  3. Revisar: Fluxo de Trabalho Típico do Git
  4. Referência e Ajuda: Usando o GitHub

Microsoft Teams

Uma equipe no Microsoft Teams foi configurada para este curso e você foi adicionado como um membro de todo o curso.

  1. Instalar o Microsoft Teams – Introdução ao MS Teams
  2. Entre no Teams com a sua conta de e-mail do byupathway.edu.
  3. Você deve ver uma equipe chamada Web Frontend Development II.
  4. Publique uma mensagem no canal Geral indicando que você está dentro e pronto para se conectar.
