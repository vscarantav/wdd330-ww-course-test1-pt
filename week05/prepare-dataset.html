S05 – Atividade de Aprendizagem: S05: Dataset

Visão Geral

A dataset propriedade HTML é uma maneira de acessar atributos de dados personalizados em elementos HTML. Isso permite o armazenamento de informações adicionais em um elemento sem afetar a estrutura HTML. A dataset propriedade é um objeto que contém todos os atributos de dados personalizados de um elemento, e cada atributo pode ser acessado usando a notação camelCase. Por exemplo, se um elemento tiver um atributo de dados de data-user-id, ele pode ser acessado usando element.dataset.userId.

Preparação

dataset é uma propriedade em qualquer elemento HTML que permite acessar atributos data-* personalizados. Isso permite que os dados sejam passados para o JavaScript sem usar atributos id ou class, que podem se tornar extensos e complexos. O uso de dataset prepara você para usar diversos frameworks de interface do usuário que usam atributos de dados para vincular dados a elementos HTML, mantendo as coisas flexíveis e declarativas no HTML.

Aqui está um exemplo de como usar a dataset propriedade:

<button data-user-id="42" data-role="admin">Edit</button>
const element = document.querySelector('#myElement');
element.dataset.userId = '12345';
console.log(element.dataset.userId); // '12345'
element.dataset.userId = '67890';
console.log(element.dataset.userId); // '67890'
element.dataset.userId = '12345';
console.log(element.dataset.userId); // '12345'
element.dataset.userId = '67890';
console.log(element.dataset.userId); // '67890'

Instruções da Atividade

Esta atividade ensinará como incorporar dados estruturados em elementos HTML usando atributos data-* e acessar esses dados usando JavaScript para construir comportamentos interativos e CSS para estilizar elementos com base nesses dados.

Configure Seu HTML

  1. Crie um arquivo HTML chamado datasets.html
  2. No arquivo HTML, crie a seguinte lista de itens: 
    <ul id="items">
  <li>Banana</li>
  <li>Carrot</li>
  <li>Blueberry</li>
</ul>
  3. Adicione os seguintes atributos data-* a cada item:
    • data-name: O nome do item (ex.: "banana", "cenoura", "mirtilo").
    • data-category: A categoria do item (ex.: "fruta", "vegetal", "laticínio").
    • data-color: A cor do item (ex.: "amarelo", "laranja", "azul").
    Avalie Seu Conhecimento 
    <ul id="items">
  <li data-name="banana" data-category="fruit" data-color="yellow">Banana</li>
  <li data-name="carrot" data-category="vegetable" data-color="orange">Carrot</li>
  <li data-name="blueberry" data-category="fruit" data-color="blue">Blueberry</li>
</ul>

Interação com JavaScript

  1. Em um arquivo de script ou tag <script>, selecione todos os itens da lista usando document.querySelectorAll e armazene-os em uma variável.
  2. Percorra cada item da lista em um laço e registre no log os valores dos atributos data-name, data-category, e data-color no console usando a dataset propriedade.
    Avalie Seu Conhecimento 
    const items = document.querySelectorAll('#items li');
items.forEach(item => {
  console.log('Name:', item.dataset.name);
  console.log('Category:', item.dataset.category);
  console.log('Color:', item.dataset.color);
});
  3. Adicione um ouvinte de eventos para que, quando o usuário clicar em um produto, seus detalhes sejam exibidos abaixo da lista.
    Avalie Seu Conhecimento 
    const items = document.querySelectorAll('#items li');
const details = document.createElement('div');
document.body.appendChild(details);
items.forEach(item => {
  item.addEventListener('click', () => {
    details.innerHTML = `
      <h2>Item Details</h2>
      <p>Name: ${item.dataset.name}</p>
      <p>Category: ${item.dataset.category}</p>
      <p>Color: ${item.dataset.color}</p>
    `;
  });
});

Estilo

  1. Estilize os itens de forma diferente com base em seus atributos data-category ou data-price.
Avalie Seu Conhecimento 
li[data-category="fruit"] {
  background-color: lightyellow;
}

li[data-category="vegetable"] {
  background-color: lightgreen;
}

li[data-category="dairy"] {
  background-color: lightblue;
}
