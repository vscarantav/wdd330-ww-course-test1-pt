S05 – Atividade de Aprendizagem: S05: Conceitos Avançados de Funções

Visão Geral

Na semana anterior Conceitos Avançados de Funções atividade, você explorou como as funções são executadas na pilha de chamadas e como podem ser usadas como objetos de primeira classe. Esta atividade continua esse estudo com quatro padrões relacionados: closures, expressões de função invocadas imediatamente (IIFE), recursão, e callbacks. Esses padrões ajudam você a gerenciar o escopo, proteger dados privados, dividir problemas em partes menores e lidar com tarefas assíncronas, tudo o que você pode aplicar em seu projeto final.

Preparação

Closures

Closures são funções que têm acesso ao escopo da função externa mesmo após a função externa ter retornado. Isso permite a criação de variáveis e funções privadas que não são acessíveis a partir do escopo global. Closures são frequentemente usadas para criar funções fábrica que retornam funções com seu próprio estado privado.

Por exemplo, o código a seguir cria uma closure que retorna uma função que incrementa uma variável contador:

function createCounter() {
  let count = 0;
  return function() {
    count++;
    return count;
  };
}
const counter = createCounter();
console.log(counter()); // 1
console.log(counter()); // 2
console.log(counter()); // 3

Neste exemplo, a createCounter função retorna uma nova função que tem acesso à count variável. Cada vez que a função retornada é chamada, ela incrementa a count variável e retorna seu valor.

Expressões de Função Invocadas Imediatamente (IIFE)

Expressões de Função Invocadas Imediatamente (IIFE) são funções que são executadas imediatamente após serem definidas. Isso permite a criação de um novo escopo e pode ajudar a evitar colisões de nomes de variáveis. IIFE são frequentemente usadas para criar variáveis e funções privadas que não são acessíveis a partir do escopo global.

Por exemplo, o código a seguir cria uma IIFE que retorna uma função que incrementa uma variável contador:

const counter = (function() {
  let count = 0;
  return function() {
    count++;
    return count;
  };
})();
console.log(counter()); // 1
console.log(counter()); // 2
console.log(counter()); // 3

Neste exemplo, a IIFE cria um novo escopo e retorna uma função que tem acesso à count variável. Cada vez que a função retornada é chamada, ela incrementa a count variável e retorna seu valor.

Este exemplo vem de uma atividade de aprendizagem anterior usando o serviço gratuito de API REST, jsonplaceholder.typicode.com.

(async () => {
  try {
    const response = await fetch('https://jsonplaceholder.typicode.com/posts');
    if (!response.ok) {
      throw new Error(`HTTP error! Status: ${response.status}`);
    } 
    const posts = await response.json();
    console.log(posts);
  } catch (error) {
    console.error('There was a problem fetching the posts:', error);
  }
})();

Neste exemplo, a IIFE é usada para criar uma função assíncrona que busca posts da API e faz o log deles no console. A IIFE é invocada imediatamente, permitindo que o código seja executado sem poluir o escopo global.

Recursão

Recursão é uma técnica de programação na qual uma função chama a si mesma para resolver um problema. Isso pode ser útil para resolver problemas que podem ser divididos em subproblemas menores. A recursão pode ser usada para criar soluções elegantes para problemas complexos, mas também pode levar a problemas de desempenho se não for usada com cuidado.

Callbacks

Callbacks são funções que são passadas como argumentos para outras funções e são executadas em um momento posterior. Isso permite a programação assíncrona, em que uma função pode continuar executando enquanto aguarda a conclusão de outra função.
